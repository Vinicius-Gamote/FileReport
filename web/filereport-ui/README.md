# FileReport UI

Angular 22 / Angular Material interface with JWT login, streamed CSV uploads, a Chart.js comparison dashboard, SignalR progress, report downloads, and explicit email requests. Complete browser end-to-end acceptance remains pending.

See the [repository README](../../README.md) for setup, current capabilities, verification, and API startup instructions. From this directory, `npm start` serves the UI at `http://127.0.0.1:4200` and proxies API requests to `http://127.0.0.1:5080`.

Use `npm ci`, `npm test`, `npm run build`, and `npm run format:check` directly. No repository command wrappers are needed. If a Windows global npm shim is broken, the root README shows how to invoke the npm CLI bundled with Node without modifying the global installation.
